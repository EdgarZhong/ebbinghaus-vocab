## 二、视觉复核（Playwright 截图 × 视觉审查）

- 截图来源：`app/e2e/__screenshots__/`（chromium-desktop / chromium-compact / webkit-desktop，42 张）。
- 执行方式：visual-judge 子代理供应商不可用，由主会话亲自逐张审查关键截图（今日/暗色今日/测试/测试会话/复习/词汇 60 词/设置/compact 今日），对照第 15 章禁止项与 16.2 质量门逐条核对。
- 结论：**PASS**。① 全部文案为行为语言，无 T0/T1/T2、算法版本、UTC、JSON 等内部术语（源码级扫描亦无泄漏，"工作量"为规格定义的用户概念）；② 主按钮 min-height 44px（tokens.css 固化）、导航行 40px、点击区充足；③ 明暗两主题对比度合格，选中态有底色+描边双重表达；④ 状态均有文字冗余（逾期徽章"逾期 N 天"、状态"学习中"），不依赖颜色单达；⑤ compact 800×600 布局压缩合理、文字换行不裁切；⑥ 每页单一视觉最强操作（今日页"下一步"卡片、测试会话"认识"主推）。

## 四、发现的问题与处置

| 问题 | 根因 | 处置 | 复验 |
| --- | --- | --- | --- |
| 设置页保存总失败（Testing Library 5 项） | 页面时区校验误把 IANA 名当 locale 传给 `Intl.DateTimeFormat`（真实浏览器同样会误拒） | 改用 `new Intl.DateTimeFormat("en", { timeZone })` 标准形态 | 测试过，浏览器走查任务 8 过 |
| Space 测试 3 项失败 | 测试未遵循规格 2.5"切换后返回进入前页面"；守卫构造不合法 | 修正测试流程；最后守卫断言改为可达路径 | 过 |
| Playwright 首跑全部连接拒绝 | `vite preview` 默认只绑 localhost(::1)，baseURL 用 127.0.0.1 | webServer 加 `--host 127.0.0.1` | 42 项过 |
| toast 断言偶发歧义 | toast 堆叠是产品语义，getBy 单数断言在堆叠时歧义 | 测试统一取最新一条（`.last()`） | 过 |
| M4 第二波报告的产品缺陷：新条目永远无法首测 | 重放状态 regularDueAt 仅由 testAnswered 派生，新条目被过滤 | 用例层 New 态视为到期 + domain 新增 learningDayStartInstant（C9） | 回归测试过 |
