- 截图来源：`app/e2e/__screenshots__/` 四视口全量重生成 + MCP 走查实拍 14 张。
- **森色系双主题**：浅色雾苔画布 `#EEF3EC` / 松烟墨 `#1C251E` / 深松主行动 `#2E5C40`；深色夜林 `#111713` / 浅苔 `#98C9A6`。14 组交互色对比度实测全 ≥4.5:1（数值注释固化在 `tokens.css`）。明暗两版逐张目检，无奶灰失真、无浑浊。
- **液态玻璃签名元素**：桌面浮动侧栏、移动端抽屉、模态框、toast、吸底保存条统一玻璃材质；画布层极轻环境苔绿渐变供玻璃折射。Chromium 下折射/高光真实可见（截图目检确认）。
- **移动端重设计（不照搬桌面）**：≤900px 侧栏隐藏；顶栏 = 汉堡（44×44）+ Space 胶囊；抽屉左滑入，点导航/背景罩/Escape 关闭；词汇详情 = 底部浮动 sheet；测试会话按钮竖排拇指可达（实测截图确认）；resize 热切换不丢数据。
- **衬线词条**：逐词测试大词/词汇卡片/详情标题衬线谱系（New York/ui-serif/Georgia），"纸质词典"身份成立。

### 2.2 WebKit 降级口径（重要，跨阶段）

- 依据：liquid-glass-react README 明示 "Safari and Firefox only partially support the effect (displacement will not be visible)"；探针实证 WebKit 26.6 能力检测三项全过但位移折射不成立（深色侧栏奶灰失真根因）。
- 处置：`Glass.tsx` 能力检测加 UA 引擎判定（`/AppleWebKit/i && !/Chrome|Chromium|CriOS|Edg|Android/i`），WebKit 降级 `.glass-fallback` 磨砂；Chromium 保留完整液态路径。
- **代价与后续**：macOS 正式 App（WKWebView）将呈磨砂而非液态玻璃；**Phase 4（Tauri 闸门）/Phase 6（正式 App）需再评估**——届时可考虑 WKWebView 专项调参或接受磨砂口径。webkit-desktop e2e 视口 14/14 全绿（磨砂形态）。

### 2.3 React 最佳实践重构（vercel-react-best-practices）

已逐条落实：VocabCard memo 化（60 词列表）、详情选中态改渲染期派生（去 effect）、函数式 setState 稳定回调、长列表 content-visibility、依赖直引（无 barrel）、useMediaQuery 带 jsdom 守卫、默认非原始 props 提升。无内联组件定义、无派生态 effect 残留。
